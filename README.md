# MAHAM

### Modules for Astroparticle, High-Energy, Astronomy and Multimessenger

**MAHAM** is a community-developed scientific toolkit of reusable, validated, and citable modules, models, and methods for astroparticle physics, high-energy astrophysics, astronomy, and multimessenger research.

MAHAM focuses on portable scientific building blocks that can be used independently or integrated into existing analysis, simulation, and reconstruction software.

## Planned scope

The project is being designed to include tools for areas such as:

- particle and astroparticle physics
- neutrino, cosmic-ray, and gamma-ray physics
- physical and astrophysical models
- fluxes, spectra, and source populations
- interactions and propagation
- statistical methods and limits
- detector acceptance, exposure, and sensitivity
- astronomical calculations
- multimessenger analyses
- general radio-frequency and antenna calculations
- scientific visualization and data utilities

## Development status

**MAHAM is currently in early development.**

The initial package architecture, scientific scope, validation framework, and contribution standards are being established. The public API should be considered unstable until the first formal release.

For the broader vision and community principles of Project MAHAM, see the organization profile.
